01 — Number Guessing Game
A CLI game where the computer picks a random number and the user guesses it with higher/lower hints.

Features
* Random number generation
* Higher/lower feedback system
* Attempt tracking with a 10-guess limit
* Input validation and play again option

What I learned
* Variables, loops and conditionals
* Functions and program structure
* Error handling with try/except
* f-strings and user input
